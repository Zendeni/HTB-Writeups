# Pro Labs

Pro Lab content is not automatically eligible for public writeups. However, section 8.3(d) of the current [Hack The Box Acceptable Use Policy](https://www.hackthebox.com/hubfs/Legal/AUP.pdf?hsLang=en) explicitly treats RPG as retired content because an official writeup is published on the platform.

- [RPG Mini Pro Lab](RPG/README.md) — publication permitted under AUP section 8.3(d); six objectives, from Artifactory to Shinra.
